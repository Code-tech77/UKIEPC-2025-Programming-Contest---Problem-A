# UKIEPC 2025 Programming Contest Problem A - Arboreal Challenge

## Overview 🧑‍💻
This simple Python program calculates the **speed of fire spread 🔥**  in a forest based on user-defined coordinates (X and Y), the number of burning locations, and a fixed time interval.

It uses basic mathematical logic to estimate how fast the fire might be moving according to the provided values.

## Features ☕️
- Accepts X and Y coordinate inputs within a defined range (0 to 10⁵) 
- Multiplies the calculated distance by the number of fire locations
- Computes speed using a fixed time of 0.1 seconds
- Displays the final fire speed value per second

## How It Works ⚙️
1. You will be prompted to enter:
   - X coordinate value  
   - Y coordinate value  
   - Number of fire locations

2. The program checks if the coordinates are in valid range.  
   If not, it displays an error message in the CLI .

3. Using both coordinates, it computes:
   - Distance for X and Y using a square-root formula  
   - Total distance multiplied by the number of fire locations  
   - Fire speed using the formula:  
     ```
     speed = distance / time
     ```

4. The final result prints as the fire speed per second 🚊 .

## Requirements
- Python 3.x 🐍
- No external libraries other than the built-in `math` module
